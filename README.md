# Letícia Pais — Psicóloga | Site

Site institucional da psicóloga **Letícia Pais** (CRP 10/11502), especializada em Terapia Cognitivo-Comportamental (TCC). O site apresenta a profissional, as áreas de atuação, as modalidades de atendimento, um blog e um formulário de contato.

**Site em produção:** https://www.leticiapaispsi.com.br

## Sobre o projeto

Landing page profissional desenvolvida para divulgar os serviços de psicoterapia, facilitar o agendamento de sessões e compartilhar conteúdo sobre saúde mental e TCC.

## Seções do site

- **Sobre** — apresentação da profissional e da sua abordagem.
- **Como posso te ajudar** — áreas de atuação: regulação emocional, neurodivergência feminina, autoestima e autoconhecimento, relacionamentos saudáveis, ansiedade e sobrecarga.
- **Modalidades de atendimento** — terapia individual e em grupo, presencial (Altamira/PA) ou online.
- **Blog** — artigos e reflexões sobre psicologia, bem-estar e TCC.
- **Perguntas frequentes** — dúvidas comuns sobre o processo terapêutico.
- **Contato** — formulário com envio direto para o WhatsApp.

## Tecnologias

- React
- Vite
- Tailwind CSS
- JavaScript

## Como rodar o projeto localmente

```bash
# clonar o repositorio
git clone https://github.com/gabbiiii-gif/LETICIAPSI.git
cd LETICIAPSI

# instalar dependencias
npm install

# ambiente de desenvolvimento
npm run dev

# build de producao
npm run build
```
